# Documentation and Handoff

- Tài liệu phải phản ánh code hiện tại; code và runtime là bằng chứng, không được bịa tài liệu.
- Khi thay đổi feature, cập nhật tài liệu trực tiếp liên quan: README, API spec, schema/ERD, UI spec, roadmap hoặc changelog.
- Không viết lại toàn bộ tài liệu nếu chỉ cần cập nhật một phần.
- Ghi rõ quyết định kiến trúc, lý do, phương án đã cân nhắc và hệ quả khi quyết định có ảnh hưởng dài hạn.
- Đánh dấu roadmap theo trạng thái thực tế: planned, in progress, blocked, done.
- Khi bàn giao, nêu cách chạy, biến môi trường cần thiết (chỉ tên biến, không giá trị secret), test đã chạy và giới hạn còn lại.
