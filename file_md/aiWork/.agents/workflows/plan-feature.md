# Plan Feature

1. Làm rõ mục tiêu và actor/use case của feature.
2. Đọc roadmap/spec và code hiện có liên quan.
3. Xác định phạm vi, ngoài phạm vi, giả định và edge cases.
4. Vẽ luồng UI/API/business/data ở mức vừa đủ.
5. Liệt kê file/module dự kiến thêm/sửa.
6. Xác định migration, permission, dependency, API compatibility và rủi ro.
7. Chia task theo thứ tự có thể kiểm thử; mỗi task có acceptance criteria.
8. Đề xuất test và cách xác minh.
9. Nếu có thay đổi lớn cần duyệt, dừng ở proposal và hỏi người dùng.
10. Không sửa code trong workflow này trừ khi người dùng yêu cầu tiếp tục triển khai.
