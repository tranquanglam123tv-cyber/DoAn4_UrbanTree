## 6. Code Review
- **Điểm tốt:**
  - Kiến trúc phân lớp rành mạch: `routes/` -> `controllers/` -> `models/` -> `services/`.
  - Không có SQL Injection: Toàn bộ truy vấn dùng Prepared Statement `?` placeholder.
  - Sử dụng Bcrypt salt rounds 10 và JWT thời hạn ngắn (15 phút) có Refresh token.
  - Đã tích hợp Helmet bảo vệ HTTP headers và Rate-limit cho các luồng OTP/Login.
- **Rủi ro:**
  - Cần đảm bảo file `.env` không bị commit lên GitHub (đã có trong `.gitignore`).

## 9. Đề xuất ưu tiên
1. **Ưu tiên 1:** Bổ sung alias route `app.use('/api/v1/trees', treeRoutes)` trong `backend/src/server.js` để API frontend và mobile gọi chuẩn restful v1.
2. **Ưu tiên 2:** Tách bundle Vite (`manualChunks`) để giảm kích thước tải ban đầu của file `index.js`.
3. **Ưu tiên 3:** Bật chế độ WAL mode cho SQLite (`PRAGMA journal_mode = WAL;`) để tối ưu hiệu năng ghi dữ liệu đồng thời.
